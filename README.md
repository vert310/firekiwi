# FireKiwi

A beautiful coming soon landing page featuring a Ghibli-style logo combining fire and kiwi elements.

## Features

- 🎨 Ghibli-inspired design with soft pastel colors
- 🔥 Animated SVG logo with fire and kiwi elements
- ✨ Smooth animations and transitions
- 📱 Fully responsive design

## Setup

Simply open `index.html` in your web browser to view the landing page.

## GitHub Setup

To push this repository to GitHub:

1. **Authenticate with GitHub CLI** (if not already):
   ```bash
   gh auth login
   ```

2. **Create a new GitHub repository**:
   ```bash
   gh repo create firekiwi --public --source=. --remote=origin --push
   ```

   Or manually:
   - Create a new repository on GitHub.com
   - Then run:
     ```bash
     git remote add origin https://github.com/YOUR_USERNAME/firekiwi.git
     git branch -M main
     git push -u origin main
     ```
